Places to launch a product, each checked by hand-verifiable facts: cost, self-promotion rules, and whether the link is dofollow.

Want this matched to your product? Try https://foxplug.com/where-to-launch — free, no signup.

A cell that says "not checked" means that fact has not been verified yet. It is never a guess. Corrections are welcome.
