# Contributing

Thanks for helping keep this list accurate. The list is only useful if every cell can be checked by a reader, so every change needs evidence.

## Adding a venue

Open a pull request that adds one row to the right table in README.md, and include in the description:

1. The venue's own URL.
2. For "Free or paid": a link to its pricing or submit page.
3. For "Self-promotion allowed": a link to its rules, or the page where launches are posted.
4. For "Dofollow": how you checked, for example the rel attribute on a listed product's outbound link.

If you do not know a value, write "not checked". Please do not guess.

## Correcting a venue

Open a pull request that changes the cell, and link the page that shows the new value. Update "Last verified" to the date you checked.

## Removing a venue

A venue that is gone, redirects elsewhere, or no longer accepts submissions can be removed. Link the page that shows it.

## What we will not add

- Venues that sell upvotes or reviews.
- Link farms and venues that exist only to sell backlinks.
- Private groups nobody can join.
